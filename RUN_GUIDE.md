# XOR Cipher (8-bit key = 11000011) — Run Guide

This package has two independent, cross-verified implementations:
- **Python** — software reference (`scripts/xor_cipher_python.py`)
- **SystemVerilog** — synthesizable RTL + simulation testbenches (`rtl/`, `tb/`)

Both were tested end-to-end and produce byte-for-byte identical results.

```
xor_project/
├── rtl/                    <- synthesizable design (give this to FPGA synthesis tool)
│   ├── xor_cipher_core.sv      combinational core: data_out = data_in ^ KEY
│   └── xor_stream_top.sv       clocked streaming wrapper (valid/ready handshake)
├── tb/                     <- simulation-only testbenches (NOT synthesized)
│   ├── tb_single_number.sv     Part 1
│   ├── tb_vector.sv            Part 2
│   └── tb_image.sv             Part 3
├── scripts/                <- Python side + helper conversion scripts
│   ├── xor_cipher_python.py    Python implementation of all 3 parts
│   ├── gen_vector.py           creates data/input_vector.hex
│   ├── gen_test_image.py       creates a sample 256x256 test image
│   ├── img_to_hex.py           PNG -> hex (for $readmemh)
│   ├── hex_to_img.py           hex -> PNG (view SV results)
│   
├── data/                   <- inputs (generated by the scripts above)
└── outputs/                <- simulation results, converted images.
```

---

## Part A — Python side (either teammate can run this first)

**Requirements:** Python 3, `numpy`, `Pillow` (`pip install numpy pillow`)

```bash
cd xor_project

# 1. (optional) generate a sample 256x256 test image — replace with your own
#    real 256x256 grayscale image if you have one (see comment in the script)
python3 scripts/gen_test_image.py

# 2. run all three parts
python3 scripts/xor_cipher_python.py
```

Expect `PASS` printed for all three parts. Outputs land in `outputs/`:
`image_cipher_python.png`, `image_decrypted_python.png`.

---

## Part B — SystemVerilog side

**Requirements:** a SystemVerilog simulator. Two options below 

### Option 1: Icarus Verilog  — what we used to verify this package

```bash
# Install (Ubuntu/Debian; skip if already installed)
sudo apt-get install iverilog

cd xor_project
```

**Step 1 — generate the input data files** (needs Python from Part A run once):

```bash
python3 scripts/gen_vector.py     # -> data/input_vector.hex
python3 scripts/img_to_hex.py     # -> data/image_plain.hex  (needs data/plain_image.png)
```

**Step 2 — Part 1: single number**

```bash
iverilog -g2012 -o outputs/sim_single.vvp rtl/xor_cipher_core.sv tb/tb_single_number.sv
vvp outputs/sim_single.vvp
```

**Step 3 — Part 2: vector**

```bash
iverilog -g2012 -o outputs/sim_vector.vvp rtl/xor_cipher_core.sv rtl/xor_stream_top.sv tb/tb_vector.sv
vvp outputs/sim_vector.vvp
```

**Step 4 — Part 3: 256x256 image** (this one takes ~65,536 clock cycles per
direction, so it prints a bit slower but still finishes in a couple of seconds)

```bash
iverilog -g2012 -o outputs/sim_image.vvp rtl/xor_cipher_core.sv rtl/xor_stream_top.sv tb/tb_image.sv
vvp outputs/sim_image.vvp
```

**Step 5 — turn the SV image results back into viewable PNGs and cross-check
against the Python output:**

```bash
python3 scripts/hex_to_img.py
```

This writes `outputs/image_cipher.png` and `outputs/image_decrypted.png` and
prints a PASS/FAIL comparison against `data/plain_image.png`.
